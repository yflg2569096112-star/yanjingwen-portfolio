这次双验证在说什么

承重——问题真、且贵；空白——不是处女地，是"交集"空白。够格进 PRD，但必须：撤掉一个假数字、把价值主张当"待 MVP 自证的假设"写、护城河押在叙事 + 判断 + 飞书多师。

承重：真且贵
续费是机构命门（中金模型生命周期利润率仅 3%、续班率越近盈亏线杠杆越大）+ VIP 多师分科有结构性统筹真空。问题侧 🟢。
价值主张是假设
"可视化→留存"机制可信（Harkin meta d=0.40，"外化/公开"还放大效应），但"拉续费"只有营销数据 + 有"做错反伤"反证 → ROI 待 MVP 自证。
空白 = 交集
竞品做了相邻 2/3（跨科罗列有/叙事有/单科评语有），没合龙。差异化只能押"跨科归因叙事 + 判断 + 飞书多师"。

⚠️ 必须先撤的雷 — "80% 因感知不到成果流失"是假的

本轮最重要的诚实修正，直接改写 L2 的一处引用（L2 E 组曾写"~80% 流失因感知不到成果"）。

  • 查无原始出处。中文语境里真实的"80%"是《家庭教育蓝皮书 2024》（34 万家长样本）：80% 家长对孩子学业感到焦虑——这是家长焦虑，不是"因感知不到成果而流失"的占比。两者被自媒体/营销张冠李戴的可能性极高。
  • 所有"效果占流失 30%~40%"全是 SaaS 厂商营销口径（功能演示/单机构 case 稿），且没把"真实没进步"和"没感知到进步"拆开 → 无法证明"感知 > 真实"。
含义：PRD / 对外材料 / 任何尽调里 不能再引"80% 因感知不到成果流失"——会被一击即破。替代写法："业内定性共识：家长感知不到成果是公认的流失主因之一"，或自己做小样本调研拿一手数字。

空白验证 — 没人做透吗

两路 agent 从家长端和飞书端双向夹逼，结论一致：不是整体空白，是交集空白。

3a · 家长端三轴：跨科整合 × 叙事化 × 老师判断 → 交集为空

✅ 串联空白

跨科目整合

多数（校宝/猿辅导/作业帮/学而思/ClassIn）单科闭环；少数"多科"是并列成绩表，罗列≠串联。

✅ 进步叙事空白

叙事化

只有照片流/作品集（ClassDojo/Seesaw），偏低龄、只记录"发生了什么"、不判断"意味着什么进步"。

✅ 跨科判断空白

老师专业判断

学而思评语、AI 生成评语有"老师的话"，但都是单科/单点，非"跨科全局判断"。

白点（三轴交集）："由懂教学的老师做判断、把孩子多科离散成果（分数/作业/课堂/习惯）主动串成一条『他这段在哪些方面变好了、为什么、下一步往哪走』的连贯叙事，交付家长去感知进步"——没有任何被调研产品做透。三个鸿沟：罗列→串联 / 数据→判断 / 记录→感知。
诚实反证：学而思在"单科数据+老师评语+进步感"已逼近天花板（差异化只能押"跨科串联"轴，不能宣称"进步感没人做"）；体制内综评（北师大 SEED/璞公英）在"跨科整合"有雏形但德育取向；"AI 一键生成评语"已红海。需补验：实测学而思/猿辅导家长端是否已悄悄做"跨科汇总"——反证白点是否成立的关键。

→ PRD 输入 （验证结果已够料，可直接起草）

PROBLEM STATEMENT
以 2026-06-09 一手家长原话开场（"四个老师分开、没人统筹协调 / 词汇谁来抓"）+ 结构性裂缝：高客单价 = 多师分科 → 跨科模块无归属 → 学管缺角色/数据/流程把成果串成给家长的统一叙事。标"一手家长原话"，不引任何无出处数字。
目标用户 / 场景
三方：①学管师（直接用户·省工时+续费 KPI）②家长（价值接收·感知进步）③多师（数据供给）。先在新航道锦秋雅思 VIP 内部跑（自带班+Project B 底座）；约束：学生/家长不在飞书组织内 → 飞书做后端引擎 + 轻量端。
为什么新航道/你能赢
判断质量（懂教学的老师）+ Project B 飞书沉淀 + 2026 飞书时间窗 + 教研语料一鱼多吃。差异化必须押：跨科归因叙事 + 判断 + 飞书原生多师汇聚 + 语培 VIP；不押：做报告/成果卡/进步感/数据聚合/AI 评语。
价值假设（可证伪，无假数字）
假设内容类型
H1 效率给学管一个"多师汇聚的跨科成果叙事卡"，整理一次 VIP 学生成果的工时 ↓ ≥ X%leading·易测
H2 感知收到成果卡的家长，对"孩子在进步 / 有人统筹"的感知评分 > 对照组leading·问卷
H3 续费收到成果卡的 VIP 家长，续费意向/实际续费 > 对照组lagging·MVP 后验
H4 护栏成果卡不会因暴露"没进步"而降低家长满意度护栏·对应 P3 反证
度量 & 风险红线
度量（诚实）：H1/H2 是 leading，MVP 快速验；H3 是 lagging，靠 MVP A/B 自证；H4 是护栏。不用"80%"那类口径。　风险红线：① P3 做错反伤（暴露停滞期→加速流失；需"如何呈现停滞期"的设计护栏）② P2 叙事陷阱（别引假数字）③ 工具侧蚕食（校宝/学而思在追数据聚合；壁垒必须在叙事+判断+飞书多师）④ 校宝暗点未核。

写 PRD 前必做的 4 个一手核验 （诚实，别跳）

  1. P5 顶到 🟢：访谈 2-3 个一线学管 + 知乎/小红书站内捞原帖，把"词汇等跨科模块系统性无人 owns"从强推理坐实为一手。
  2. 实测学而思/猿辅导家长端：阶段报告是否已悄悄做"跨科汇总"——反证家长端白点是否成立的关键。
  3. 校宝/校管家产品 demo 核验："一个学生能否看到全部老师的汇聚视图、并一键出家长成果卡"——唯一可能翻盘的暗点。
  4. 鲸小爱：确认停用 + 为什么停；并在 VIP/反馈群再捞 5-10 条同类家长发言，验证"课后/统筹缺口"是高频共性（补全 L2 存疑项）。
