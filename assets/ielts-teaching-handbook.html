基础层 基础层：定位词体系（所有题型通用） ▶
Band 通用 定位词两级体系
基础讲法（Band 5–6）

大定位（原词出现）：专有名词、人名、地名、数字、时间——直接在原文搜索，最可靠。小定位（不原词出现）：only / however / initially / then / finally / but——这些词标志着考点在其后。

进阶讲法（Band 6–7）

主旨词排除：文章标题中出现的核心词（如 domestication）贯穿全文，不能作定位词——用它找会找到几十处。引号定位（匹配题专用）：选项中带引号的词组通常不被替换，可直接搜索。

高阶讲法（Band 7–8+）

双定位法：当同一大定位词在两道题中重复出现，先找第二道题定位，再往前回溯第一道题——顺序原则保证第一题在第二题前。

💡找到定位词就以为找到了答案。定位词帮你找到段落，统一替换帮你找到具体句子——这是两步，不是一步。
🔭给学生5道题，每道先圈定位词，判断大定位还是小定位，标注完再去文章找——比直接读快3倍。

第1章 第1章　填空题 Sentence Completion ▶
Band 5→6 填空题三步做题法
基础讲法（Band 5–6）

Step 1 预判词性：90%填名词，9%形容词，<1%动词。默认先填名词。
Step 2 找大定位：用专有名词/数字在原文锁定段落（顺序原则：题目顺序=原文顺序）。
Step 3 找统一替换：题干动词/形容词 ≠ 原文动词/形容词，必须找同义词对应。

进阶讲法（Band 6–7）

答案平移规则：找到答案词后，直接从原文复制，不改形式（含复数s、时态、大小写）。
双定位法：大定位词在两题重复时，先找第二题，再往前回溯第一题位置。

高阶讲法（Band 7–8+）

生词不慌原则：不认识的词不等于做不出来。通过「定位词锁定段落 → 统一替换锁定句子 → 上下文语义确认答案」，90%生词题可以做对。课堂原话：「这个词你以后估计也不会再看到了——不需要知道它什么意思，通过定位和逻辑链找出答案词。」

💡找到大定位就以为找到答案，但答案在定位词附近好几句之外。「定位词帮你找到段落，统一替换帮你找到具体句子——这是两步。」
🔭给学生一道填空题+原文，让他们画出「题干词→原文词」的替换路径，不直接找答案。做10题替换路径练习，比做100道普通题更有效。

Band 6→7 跨句指代：答案在上一句的指代关系里
基础讲法（Band 5–6）

识别特征：题干有「which/that + 关系从句」描述某物的功能，但找不到直接对应句。
解法：往前一句找「These / They / It / This」等代词，代词所指就是答案。
例：Q21 ditches——原文①「They dig ditches」→ 原文②「These are then used to drain」→ These = ditches

进阶讲法（Band 6–7）

记忆口诀：「功能句在后，名称句在前。」凡是题干描述某物功能或用途，答案词往往在描述该功能的前一句。

高阶讲法（Band 7–8+）

不只是 These/They，任何指代关系都可能跨句。动词主语也可能是指代：「Logging companies dig ditches... [These structures] are then used to drain」——理解这种句式能处理更复杂的指代题。

💡只看功能句（drain water out），以为答案是 water 或 peatlands，忽略了 These 的指代。必须追问：「These 指的是上一句的哪个名词？」
🔭给学生5道含代词（these/they/it/this）的填空题，要求写出「指代词→指代对象」的关系链，而不是直接找答案。

学生填了water 或 peatlands

Band 5→6 ONE WORD ONLY 选词原则
基础讲法（Band 5–6）

原文是两个词时（如 forest fires / carbon emitters），判断哪个词是「真正要传达的新信息」，只填那个词。

进阶讲法（Band 6–7）

判断规则：题干已经给出了修饰词的语境 → 只填核心名词。
「X value」结构 → 填X不填value（被破坏/被影响的是X）。
题干缺少修饰词信息 → 两个词都要填（若题目允许）。

高阶讲法（Band 7–8+）

判断口诀：「哪个词是这道题真正要传达的新信息？」通常是名词性核心词，修饰词（forest / severe / large-scale 等）往往可以省略。

💡Q19原文是 forest fires，学生填了 forest fires 两个词——ONE WORD ONLY 时，题干语境已有足够信息，只填 fires。
🔭给学生10道 ONE WORD ONLY 的题，专门找原文是两个词的题目，练习判断「填哪个词」而不是直接填。

Band 6→7 冒号法则：题干冒号后面是解释，不是答案
基础讲法（Band 5–6）

题干结构：「Draining peatlands leads to ___ : a serious problem which can eventually result in coastal flooding.」
冒号后的内容是解释，帮你确认答案方向，但答案本身在冒号前的空格。

进阶讲法（Band 6–7）

正确做法：先读冒号后的内容，理解答案的「类型/范围」，再回到冒号前找答案词。
Q22：冒号后说「会导致 coastal flooding 和 land loss」→ 确认方向，答案在冒号前。

高阶讲法（Band 7–8+）

冒号后的解释通常包含两类信息：①答案的性质（a serious problem / a key factor）②答案的结果（leads to flooding）。两类信息都用于确认，不用于填写。

💡学生把冒号后的词（flooding / problem）填进去——冒号后是解释不是答案，答案在冒号前。课堂原话：「冒号就是解释这个东西，是个prompt。」
🔭每次看到题干有冒号，让学生先读冒号后的内容理解「答案的类型」，再回到冒号前找词——形成习惯后自动跳过这个陷阱。

Band 5→6 「X value」结构辨析：被破坏的是X不是value
基础讲法（Band 5–6）

当原文出现「[名词] value」结构，被描述/被破坏/被影响的对象是名词（X），不是 value。
例：biodiversity value → 被破坏的是 biodiversity，填 biodiversity 不填 value。

进阶讲法（Band 6–7）

判断方法：看题干的动词在做什么（destroys / loses / reduces）→ 这个动作的对象是X（生物多样性本身），value 只是说明这个X有价值。

高阶讲法（Band 7–8+）

迁移：同样的逻辑适用于其他「X quality / X level / X rate」结构。被影响的永远是X本身，quality/level/rate 是修饰词。

💡学生看到「destroys the ___」和原文「biodiversity value」，直接填 value——「destroys value」表面上也说得通，但原文说的是生物多样性被消灭，不是「价值」被消灭。
🔭给学生5组「X value/quality/level」结构，让他们判断「如果题干是 destroys the ___，应该填哪个词」，建立直觉。

第2章 第2章　判断题 True / False / Not Given ▶
Band 5→6 三种答案的唯一条件
基础讲法（Band 5–6）

TRUE：题干所有信息与原文一致（允许统一替换，方向一致）。
FALSE：题干某一处与原文直接矛盾（仅一个词/短语级别矛盾，其余能对应）。
NOT GIVEN①（无中生有）= 原文完全没有这个逻辑。
NOT GIVEN②（无端比较）= 原文没有比较概念，题干有。

进阶讲法（Band 6–7）

FALSE vs NG 区分口诀：先问「原文有没有这个概念」。有→找矛盾，有矛盾=FALSE。没有→NG。
FALSE的矛盾通常是：①形容词反义（first ↔ not first）②数量不同 ③否定变肯定。

高阶讲法（Band 7–8+）

无端比较识别：题干出现比较词（more than / faster than / the first），但原文只有陈述没有对比→NG。做题前先扫题干有没有比较词，有则警惕NG。

💡学生常把「我没找到」误认为是NG——但「没找到」可能是定位没做好。先用大定位锁定段落，在那个段落里找矛盾，找不到矛盾才是NG。
🔭自己出题训练：给学生一段原文，让他们写3道判断题（1TRUE/1FALSE/1NG）。比做100道题更有效，因为出题时必须理解NG的设计逻辑。

Other countries had built underground railways before Metropolitan Line.FALSE原文：Metropolitan Line 是 world's FIRST underground railway。题干暗示「之前已有其他地铁」= 与原文直接矛盾。
More passengers than predicted on the first day.NG原文只说「almost 40,000 passengers」，没有预测数字。题干出现比较（actual vs predicted）但原文无此比较 → 无端比较型NG。
Ventilation system proved difficult to prevent pollution.TRUEhowever转折后：原文「remained a problem」= 依旧是问题 = 与题干「difficult to prevent pollution」方向一致。

The railway was a financial success from the start.FALSE原文「did not make a profit」= 没有盈利；题干「financial success」= 直接矛盾。
Electric locomotives introduced more quickly than steam ones.NG原文只提到电力机车，没有「引入速度」比较的概念 → 无中生有型NG。

第3章 第3章　人名匹配 Name Matching ▶
Band 5→6 人名匹配四步法
基础讲法（Band 5–6）

Step 1：圈出所有人名（第一次全名，第二次起只有姓，不要漏）。
Step 2：只看两类内容：①引号内的话 ②says/notes/adds/argues/indicates/claims 后内容。
Step 3：简化每个选项为2–3个核心词（主语+动作+宾语；去掉主旨词）。
Step 4：匹配时至少对上2个核心词才能选。

进阶讲法（Band 6–7）

NB规则：出现NB = 有一个人名被用两次。提前标记，不然做到最后发现少一道题。
没有NB = 每个人名各用一次，可以用排除法。

高阶讲法（Band 7–8+）

高效策略：不通读全文。直接在文章里找4个人名，每找到一个立刻看引号内容，与4道题对照。通常一轮就能全做完——每个专家的观点高度独特，不会混淆。

💡答案有时是专家「顺带说的一句话」（如Q26 van Eijk在C段），不是他在那段的核心观点。段落主旨法找不到，只有人名定位+引号搜索才能稳定找到。
🔭观点归属训练：给学生含多个专家引用的文章，不给题目，让他们用一句话写出每个专家的核心观点。训练快速提炼他人立场的能力。

Band 6→7 多选题做题策略：分散型 vs 密集型
基础讲法（Band 5–6）

分散型：答案分布在文章不同段落，每道题对应不同区域，按题号顺序找即可。
密集型：所有答案集中在同一段或相邻段落，需要先把全部选项看懂，再在一段内集中比对。

进阶讲法（Band 6–7）

判断题型的方法：
① 分散型：每道题通常有独立定位词（人名/时间/专有名词），和其他题的定位区域不重叠。
② 密集型：题目问的都是同一个话题下的不同方面，定位词高度相似或集中在一个段落标志词后。
课堂原话：「分散的，和金字塔那篇有点像；密集的，就像在一段里找两个」

高阶讲法（Band 7–8+）

分散型优先按顺序原则做；密集型需要先简化所有选项为2-3个核心词，再统一进段找对应——不要边读边对，容易漏。

💡看到多选题先不急于找定位，先判断是分散还是密集。分散型每题独立做；密集型先通读选项再集中比对。
🔭给学生两道多选题（一分散一密集），让他们先判断类型，再用不同策略做——目的是让他们主动识别题型而不是无脑找定位。

Band 7→8 单选题两种题型：细节推理题 vs 段落推理题
基础讲法（Band 5–6）

细节推理题：能定位到具体原句，做法和多选题类似——找定位词→锁定句子→排除陷阱选项。
段落推理题：需要读完整段，归纳段意，再把段意与选项对应——不能靠单句定位。

进阶讲法（Band 6–7）

优先级策略：碰到单选题先判断类型。细节推理题先做；段落推理题如果读不懂段意，放在最后做——这类题是Reading中难度最高的。
判断方法：题干问「根据X段作者说明了什么」或「第X段的主要观点是」→段落推理题；题干有明显定位词→细节推理题。

高阶讲法（Band 7–8+）

陷阱识别核心：单选题最多陷阱就是「细节正确但方向错」。看到的细节在原文里确实提到了，但整段的逻辑走向是反驳这个细节或者说明别的事情。解题关键是先抓主旨句（段首+段尾），再看细节在段中的作用。
课堂原话：「千万不能被细节陷阱带跑——你要看他在讲的到底是什么，他这一段的主旨到底是什么。」

💡最常见错误：看到某个选项的词在原文出现了，就选那个——但这个词出现的位置可能是旧观点、举例或者被反驳的内容，不是作者的主张。
🔭练习：做完单选题后，不看答案，先写出「这道题我选XX因为我认为段意是……」——迫使自己用段意选题而不是词汇匹配。

Band 7→8 Summary填空匹配：二次匹配法
基础讲法（Band 5–6）

本质是填空题，但答案不从原文直接抄，而是从给定的A-K词库（名词/形容词）中选。
二次匹配：①先根据题干找定位，确认原文中的对应词/概念；②再在A-K选项里找哪个词能替换原文该词。

进阶讲法（Band 6–7）

预判词性：空格前后能判断词性（名词/形容词），可以先排除掉选项里不符合词性的词。
逻辑预判：题目顺序=原文顺序，做前几道对了可以用来缩小后几道的范围。
课堂原话：「你可以根据前5个猜一下，这类题猜的正确率是比较高的。」

高阶讲法（Band 7–8+）

当A-K里有生词：先把认识的词和已确认的答案对应完，剩余选项对应剩余空格，这是一种有效的排除策略。
高频词汇提示：appeal（名词=吸引力）、devote（投入/奉献）、innovation（创新）、satisfaction（满足感）——这几个词是常考替换词。

💡陷阱：原文出现了某个词，就直接填那个词——但正确做法是找A-K里能替换原文词的选项词。有时原文词根本不在选项里（比如原文是rewarding，选项是satisfaction）。
🔭专项练习：做完题后，写出「原文词→我选的选项词」的替换路径，确认自己理解了替换关系而不是靠猜。

Band 5→6 Introduction 两句法
基础讲法（Band 5–6）

句1：改写题目背景（不抄题，用同义词/句式变换）。
句2：表明立场 + 让步短语。
最简公式：[背景改写]. Despite [让步], I believe [立场].

进阶讲法（Band 6–7）

让步三选一：
· despite causing some minor disruption to [X]
· while this trend carries certain drawbacks for [Y]
· although [反方一句话], [正方立场].

高阶讲法（Band 7–8+）

名词化改写背景：把题目动词改成名词短语做主语。「people reduce flights」→「A reduction in air travel」
高阶立场：primarily because [一句最强理由], outweighing the associated drawbacks.

💡立场过于绝对（I totally agree）。加 despite/although 短语，立刻显示双边思维。
🔭练习：给学生三道题，只写Introduction两句，批改只看：①背景有没有改写 ②立场有没有让步。

Band 5→6 三层逻辑链：行为 → 原因 → 结果
基础讲法（Band 5–6）

最常见问题：跳过「原因层」，从行为直接跳到结果，论证悬空。
模板：[行为] + because [中间机制] + , leading to/thereby + [结果]

进阶讲法（Band 6–7）

扩展四层链：[行为] → [直接原因] → [直接结果] → [延伸结果]
例：减少飞行 → 航班减少 → 航空收入下滑 → 行业整体衰退

高阶讲法（Band 7–8+）

动名词主语版（Band 7+）：[动名词行为] has been shown to [结果], primarily because [深层机制], which in turn [社会延伸效果].

💡写「飞行减少→环境好」直接跳步。追问：「怎么好的？哪个具体机制？」必须说出中间那一步。
🔭自查清单：写完Body段，在每句旁标注「行为层/原因层/结果层」，连续两句同一层 = 需要补充另一层。

Band 6→7 三层统一替换体系
基础讲法（Band 5–6）

不是同义词替换，而是把同一概念升级成不同句法结构。
基础：reduce travel → harm the tourism industry

进阶讲法（Band 6–7）

进阶：a decline in air travel → restrict individuals' access to opportunities（名词化+精确结果）

高阶讲法（Band 7–8+）

高阶：curtailing long-haul aviation → exacerbate socioeconomic disparities between urban and remote regions（动名词主语+学术词+城乡差距）

💡只换词不改句型，升级后反而不自然。先改主语表达方式（动词→名词化），再改动词——两步分开做。
🔭给学生5个核心动词（increase/improve/reduce/cause/affect），各写三个版本，不限话题，训练句法意识。

①引入（人物/主题）→ ②核心特质 → ③具体事件 → ④细节深化（加转折/困难）→ ⑤正面感受 → ⑥对比/反思

进阶讲法（Band 6–7）

结构模板：I'd like to talk about [主题]. [核心特质一句话]. [具体事件引入]. However, things did not always go smoothly — [转折/困难]. [解决过程]. Eventually, [结果]. I felt [感受] because [原因].

高阶讲法（Band 7–8+）

高阶版在「困难」部分加具体细节（数字/引用/行为细节），在「感受」部分说清楚为什么有这个感受——不是「I felt happy」，而是「I was proud because he embraced new technology at an age when most people of his generation were reluctant to change」。

💡平铺直叙没有转折，听起来像背课文。追问：「后来有没有遇到什么挑战？」哪怕一个小转折也能让故事更真实。
🔭结构训练：给学生一个话题，要求先用六个词（每部分一个词）列出提纲，然后展开。批改时只看六个部分是否都出现了。

Band 6→7 素材串联策略：一个素材覆盖多个话题
基础讲法（Band 5–6）

同一个人/事件，通过改变「切入角度」和「结尾感受」，可以回答完全不同的话题。准备好一个素材 = 同时准备好6–8个话题的答案。

进阶讲法（Band 6–7）

操作步骤：①建立一个有故事性的核心素材（人物+事件+转折+结果）②列出这个素材能回答的所有话题 ③每个话题只改：切入角度（开头如何引入）+ 结尾感受。

高阶讲法（Band 7–8+）

串联示范（叔叔AI转型素材）：proud of family member / gave advice / person who encourages / piece of technology / used imagination / many people smiling——同一个事件，六个不同切入。

💡学生为每个话题单独准备素材，效率极低。核心目标：让学生意识到「一个好素材 = 多个话题的答案」，每次备考只需准备3–4个高质量素材。
🔭串联练习：给学生一个素材，列出它能回答的所有话题，分别写出切入角度（不改核心故事，只改第一句和最后一句感受）。

基础讲法（Band 5–6）

💡学生把 Part 3 当 Part 2 来说，每题超过一分钟，结果考官只来得及问 2-3 道题，无法全面展示回答能力。

Band 5→6 听力填空题三步做题法
基础讲法（Band 5–6）

Step 1 预判词性：90% 填名词，少数填形容词（系动词 become/is/was 后预判形容词），极少填动词。默认先预判名词。
Step 2 找大定位：用专有名词/数字/时间在录音中锁定对应片段（顺序原则：题目顺序=录音顺序）。
Step 3 找统一替换：题干词≠录音词，必须找同义词对应，确认替换后再填答案——不能听到一个词就直接填。

进阶讲法（Band 6–7）

数字考点：只写数字，不写单位词（填 321,000 不填 three hundred thousand）；approximately / about / around 均可替换 approximately；thousand=后三个零，million=后六个零。
细节词 > 概括词原则：如果录音提供了更细的描述词，填细词（填 slaves 而非 workers，填 taxation 而非 method）。

高阶讲法（Band 7–8+）

转折强调词后大概率是答案：in fact / however / but / although 等表示强调或转折，考点往往紧跟其后。
系动词后接形容词：题干出现 become/is/was + 空格，预判填形容词，不要填名词。

💡听到定位词就以为找到答案，但答案可能在定位词之后好几句之外。另一个常见错误：填太概括的词（workers 而非 slaves，method 而非 taxation）——要尽量填录音中出现的最细的对应词。
🔭每题做完后对照录音，画出「题干词 → 原文词」的统一替换路径，不只是对答案。专门做 P4 填空题 10 道，重点练习数字题和词性预判。

Band 6→7 并列结构锚定法
基础讲法（Band 5–6）

当题干中出现已知词（如 web browser），在听力中一旦听到该已知词，随后出现的 and / then / also 等并列连词之后的词就是答案。不需要理解整句话，直接锁定并列连词后面的词。

进阶讲法（Band 6–7）

双答案在同一句：相邻两题的答案有时会在录音的同一句话里连续出现（如 Q36 和 Q37 的答案紧跟在并列句中），听到第一个答案后不能放松，要继续听下一个答案。

高阶讲法（Band 7–8+）

举例并列变体：有时并列不用 and，而是用 for example / such as 引出，此时已知词出现后紧跟举例连词，然后列举出答案（题干有 X and ___ → 录音说 such as X and ___，直接填 ___ 后的词）。

💡只盯着当前一道空，听到一个词就停下来记录，错过了紧跟着的下一个并列答案。
🔭练习时，专门用一张纸记录「题干已知词 → 听到的并列连词 → 答案」路径，感受锚点效果。注意区分并列锚定（and/also/then）和举例锚定（such as/for example）。

Band 6→7 听力选择题：时间顺序词定位法
基础讲法（Band 5–6）

听到 initially / first / next / then / already / now 等时序词时，立刻判断该信息处于哪个时间段（过去/当前/将来），再匹配题目的时间限定（如 do next = 下一步 = 听 next/then/after 之后的内容）。

进阶讲法（Band 6–7）

题目若问 'do next'，答案一定在原文出现时序词之后的信息。原文说 'initially...X' 则 X 是过去/第一步行为，若题问 next 则必须排除。序数词（first/second）和状态副词（already=已完成、still=尚未结束）同样起定位作用。

高阶讲法（Band 7–8+）

考场实操三步：①先圈题目的时间限定词（next/before/first/already）→ ②在原文中匹配同义时序词 → ③判断该时序词后面的动作是否与选项匹配。时序词误用是最常见丢分点——题目问 next 却选了 initially 后面的内容。

💡题目问 do next，学生却选了最先提到的内容，原因是没注意时序词 initially，把第一步行为当成下一步行为。
🔭训练时主动圈出所有时序词，再反推题目问的时间段，确认匹配后再选。推荐用剑雅 Section 3 对话题型练习（有多个说话者转换 + 时序关系）。

Band 6→7 听力选择题：原词复现陷阱（负面评价=干扰项）
基础讲法（Band 5–6）

在听力选择题中，当某个选项的关键词在原文中出现时，不能直接选——必须继续听说话者的态度。如果说话者对该词给出了负面评价或否定语气，该选项就是陷阱，不是答案。

进阶讲法（Band 6–7）

原词复现是听力最常见的干扰手段。判断步骤：① 听到选项关键词出现 → ② 继续听，判断说话者态度（正面/负面/中立）→ ③ 负面或否定语气 → 排除该选项。常见负面标志：refuse / can't do anything with / eats into / rubbish / found it difficult / wasn't working 等。

高阶讲法（Band 7–8+）

双维判断法：把选项分为「原文有提到 + 正面」「原文有提到 + 负面（陷阱）」「原文未提到（可能是正确/无中生有）」三类。考场中大多数错误来自只判断了「原文是否提到」而忽略了「说话者态度」这第二维度。

💡听到选项原词就直接选，没有继续听说话者对该选项的评价，导致选了负面评价的选项（典型陷阱）。
🔭训练时：选题前先回忆听到该词时说话者的语气，用一秒钟判断正面/负面，再做选择。配合做题后回放原文，确认自己是否忽略了态度词。
