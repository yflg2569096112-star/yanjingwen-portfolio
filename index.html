自我介绍

你好，我是闫敬文。我把一线教学和教务工作里遇到的问题，做成了四个可打开的 GitHub 项目：「伴课」AI 教学服务展示站、「智排教室」状态核验工作台、雅思写作教师检索入口和学生口语复习卡。它们不只是方案文档，招聘方可以直接体验页面、查看仓库和项目边界。我现在是一线雅思教师，累计授课约 1900 小时；此前有 3 年专业声音设计与音频工程经验。我希望把这种从场景发现问题、动手做原型、记录质量与人工确认点的工作方式，用到 AI 教育应用、解决方案或内容工作流岗位。
